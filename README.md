
  # Photography Website

  ## Roadmap
  
  - Switch to using google albums for various galleries.
    - json store for gallery data
    - implement google album api
    - fetch image urls from google album api
  - Implement a blog section with markdown support.
    - markdown parser for blog posts
    - implement blog post api
  - Migrate to svelte kit
  - Admin website with github auth for adding/editing blogs or using a github repository for blog.
  
  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
